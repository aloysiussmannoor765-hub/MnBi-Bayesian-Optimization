# MnBi-Bayesian-Optimization

## Overview

This project investigates the use of multi-objective Bayesian optimization
for the computational design of doped MnBi alloys.

## Objectives

The optimization targets:

- Magnetocrystalline anisotropy energy (MAE)
- Curie temperature (Tc)

## Computational Methods

- Density Functional Theory (DFT)
- EMTO
- SPR-KKR
- Gaussian Process regression
- Bayesian Optimization
- qEHVI
- Python
- BoTorch

## Workflow

EMTO structural relaxation → SPR-KKR calculations → MAE and Tc
→ Gaussian Process models → qEHVI → candidate selection
→ DFT validation
